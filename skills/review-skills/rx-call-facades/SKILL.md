# Фасады вызовов

Межслойное и межмодульное взаимодействие идёт только через генерируемые фасады.

| Фасад | Что вызывает |
|---|---|
| `this.{Метод}(...)` | метод того же класса и слоя |
| `Functions.{Сущность}.{Метод}(_obj, ...)` | экземплярная функция своего модуля в том же слое. Сущность передаётся **первым аргументом** — контракт платформы |
| `Functions.Module.{Метод}(...)` | модульная функция своего модуля в том же слое |
| `PublicFunctions.{Сущность\|Module}.{Метод}(...)` | функция другого модуля; доступны только методы с `[Public]` |
| `{Фасад}.Remote.{Метод}(...)` | вызов серверной функции из клиентского или разделяемого кода; метод помечен `[Remote]` |
| `IsolatedFunctions.{Область}.{Метод}(...)` | функция изолированного слоя |
| `Constants.{Сущность\|Module}.X` | константа своего модуля |
| `PublicConstants.{Сущность\|Module}.X` | константа другого модуля; на константе нужен `[Public]` |
| `Structures.{Сущность\|Module}.I{Имя}` + `.Create()` | прикладная структура |
| `Resources.{Ключ}` / `Resources.{Ключ}Format(a, b)` | ресурс текущего типа; `Format` генерируется, если в значении есть плейсхолдеры |
| `{Сущности}.Resources.{Ключ}` | ресурс другого типа (`OfficialDocuments.Resources.X`) |
| `Queries.{Сущность\|Module}.{ИмяSqlФайла}` | предопределённый SQL из `Queries/*.sql` |
| `AsyncHandlers.{Имя}.Create()` … `.ExecuteAsync()` | постановка асинхронного обработчика в очередь |

## Правила

- Слой вызываемой функции определяется слоем **вызывающего файла**. `Functions.Module.X` в файле из `Server` — серверный `ModuleFunctions`, тот же вызов в `ClientBase` — клиентский.
- Допустимые направления: клиентский код → разделяемый и серверный; разделяемый → серверный; серверный → серверный и разделяемый.
- Разделяемый код исполняется и на клиенте, и на сервере, поэтому к серверным функциям из Shared обращаются через `.Remote.`.
- Серверные функции **своего** модуля из серверного кода вызываются напрямую, без `Remote`.
- Функцию другого модуля с `[Public, Remote]` из серверного кода штатно вызывают так: `PublicFunctions.X.Remote.Y(...)`.
- Фасадные вызовы пишутся без `this`.
- Каждый `.Remote.` — обращение к серверу и сериализация. Не вызывать его в цикле: передавать весь набор за один вызов.
