# Безопасность, ресурсы, константы, структуры, форма

## Безопасность

- Учётные данные, токены и секреты не хранить в коде (ни литералом, ни константой). Значение вводит пользователь или оно читается из справочника «Параметр системы» через `Commons.PublicFunctions.Module.GetParameterPasswordValue`.
- В свойстве сущности секрет — только зашифрованным: `Encryption.Encrypt` / `Encryption.Decrypt`. Собственное шифрование или хеширование секретов не писать.
- В поле ввода диалога ранее сохранённый секрет не подставлять: пустое `dialog.AddPasswordString(...)`; в отображаемое свойство писать маску.
- MD5 и SHA-1 не применять для паролей, токенов, подписей и контроля целостности. Для некриптографической метки или сравнения содержимого допустимы (`GetMD5Hash`, `GetFactLabel`).
- URL, IP-адреса и пути к внешним ресурсам не писать литералом: константа модуля или сущности (`*Constants.cs`) либо параметр настройки со значением по умолчанию.
- SQL не собирать конкатенацией или форматированием строк из пользовательского ввода и данных внешних систем. Подстановка числовых идентификаторов и имён временных таблиц в предопределённый запрос (`Queries.*`) через `string.Format` / `ExecuteSQLCommandFormat` допустима.
- Текст SQL не писать инлайн в C#: запрос в `Queries/*.sql` модуля или сущности, вызов — `Queries.{Сущность|Module}.{ИмяSqlФайла}`.

## Освобождение ресурсов

- `IDisposable` освобождается через `using` или `finally` во всех ветках, включая ранний выход и исключение: потоки (`MemoryStream`, `StreamReader`), хеш-провайдеры (`MD5.Create()`), объекты ADO.NET (`SQL.GetCurrentConnection().CreateCommand()`, `ExecuteReader()`), сессии (`new Sungero.Domain.Session()`).
- Ресурс, созданный в выражении вызова, объявлять отдельным `using`: `using (var sourceStream = version.Body.Read()) sourceStream.CopyTo(stream);`, а не `version.Body.Read().CopyTo(stream)`.
- Объект из `using` не возвращать из метода: к использованию он уже освобождён. Если метод отдаёт ресурс наружу — без `using`, освобождает вызывающий.
- `HttpClient` и `HttpClientHandler` — через `Http.CreateHttpClient()` / `Http.CreateHttpClientHandler`, а не `new`.
- Блокировки — только через `Locks` (`TryLock`, `Lock`, `Unlock`, `GetLockInfo`); оператор `lock` не использовать.

## Ресурсы локализации

- Все тексты, которые увидит пользователь, — в ресурсах (`*.resx` английский, `*.ru.resx` русский), не в коде. В английском допустимо значение `TODO`. Ресурс добавляется в файлы ресурсов и в поле `ResourcesKeys` метаданных.
- В `*.ru.resx` и других целевых локалях не оставлять `TODO`, `TBD` и пустые значения; строка соответствует языку локали.
- Плейсхолдеры `{0}` — только если аргументы реально передаются через `Resources.{Ключ}Format(...)`.
- Сообщения логов в ресурсы не выносить.

## Константы

- Константы — в специальных классах: `ModuleConstants.cs` для модуля, `{Сущность}Constants.cs` для сущности.
- Связанные константы группировать во вложенный класс; имя не повторяет префикс группы (`Colors.Purple`, а не `Colors.ColorPurple`).
- Таймауты и пороги — именованные константы или параметры настроек, не литералы в месте вызова.
- Расширения файлов, типы документов и общеупотребимые значения — публичные константы платформы или модуля-владельца (`Docflow.PublicConstants.Module.SgnExtension`).
- Строковые ключи `Params`, словарей и `AdditionalParams` — константы модуля-владельца, одна и та же при записи и чтении.
- `Commons.PublicFunctions.Module.GetParameter*Value` — передавать `Code` и `DefaultValue` константы параметра (`Commons.PublicConstants.Module.DefaultParametersProperties.{Параметр}`), не строковый код; значение по умолчанию через `??` не подставлять.

## Структуры и прочее

- Для объединения данных — прикладные структуры: создаются `.Create()` без параметров, каждое свойство ставится отдельно.
- `System.Linq.Expressions.Expression` не использовать — лямбды или делегаты. К `[ExpressionElement]` (no-code) не относится.
- Устаревший код не удалять: `[Obsolete]` с указанием новой версии метода/модуля и перенос в `partial`-класс `Obsolete*.cs`.

## Карточка и элементы формы

- Невидимые контролы — не хранилище дефолтов.
- Не дублировать видимость через `State.Properties.*.IsVisible` в `Refresh`, если она уже управляется `Hide`/`Show` в обработчике изменения связанного свойства.
- `IsEnabled` свойства не привязывать к заполненности другого поля без прямой логической зависимости.
- UI, зависящий от лицензии, — одна и та же проверка лицензии во всех контекстах: карточки, формы заданий, no-code.
