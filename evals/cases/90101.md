## Description
ПОРЯДОК ДЕЙСТВИЙ:
В карточке роли ИИ-агента у инструмента поиска по QA в поле «Параметры» оставить только пробелы и открыть выбор областей поиска (серверная функция GetSelectedAreasForQASearchTool модуля Sungero.Commons).

НАБЛЮДАЕМЫЙ РЕЗУЛЬТАТ:
Строка из пробелов считается заполненной, функция пытается разобрать её как JSON и падает с ошибкой.

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
Строка из одних пробелов считается пустой: области не выбраны, ошибки нет.
